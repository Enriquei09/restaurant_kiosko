# Sonidos de notificación

Coloca aquí el archivo `new_order.mp3` para la notificación de nueva orden en cocina.

- **Duración recomendada:** 0.5 – 2 segundos
- **Formato:** MP3 o WAV
- **Archivo requerido:** `new_order.mp3`

Puedes obtener un sonido de notificación gratuito en:
- https://mixkit.co/free-sound-effects/notification/
- https://freesound.org
